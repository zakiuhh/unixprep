<p style="font-size: 20px; text-align: center">🎓 FAST — Entry Test</p>

Prep resources for FAST-NUCES's own admission test, used across FAST's campuses (Karachi, Lahore, Islamabad, Peshawar, Chiniot-Faisalabad) for CS, engineering, and business programs.

## 📋 About the Test

FAST's entry test generally covers Mathematics, English, Analytical/Quantitative reasoning, and sometimes basic computer/logic questions, depending on the program. It's a fast-paced, MCQ-based test — speed matters as much as accuracy.

## 🗂️ Contents

This folder is currently a flat collection — as you add material, consider organizing it into subfolders like:

```
FAST - Entry Test
├── Past Papers
├── Math
├── English
└── Analytical Reasoning
```

## 📝 How to Use

1. Get comfortable with analytical/quantitative reasoning questions first — this is usually where students lose the most time.
2. Drill past papers under strict timing since FAST's test is known for being fast-paced.
3. Brush up on basic English grammar and vocabulary — don't skip it assuming it's "easy."
