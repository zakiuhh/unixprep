<p style="font-size: 20px; text-align: center">🏗️ NED — NED University Entry Test</p>

Prep resources for NED University of Engineering & Technology's own entry test, used for engineering admissions in Karachi.

## 📋 About the Test

NED's entry test covers Mathematics, Physics, Chemistry, English, and a Computer/IT section — matching the subject folders below. It's based on FSc Pre-Engineering syllabus with NED's own question style, which tends to be more conceptual than pure memorization.

- **Chemistry / Computer / English / Maths / Physics** — subject-wise notes and practice material.
- **NED Combined Past Papers of All Subjects** — full past papers covering all sections together, good for timed mock attempts.
- **Practice MCQs** — extra MCQ sets for targeted drilling.
- **SAP 8th Edition Prep book** — ⚠️ this is a commercially published prep book. If your copy came from a paid source, consider replacing this folder with a link to where students can purchase it officially, rather than hosting the file — see the root README's note on copyright.

## 📝 How to Use

1. Work subject-by-subject first using the individual folders.
2. Once comfortable, move to the combined past papers for full timed mocks.
3. Use Practice MCQs for topics you're still shaky on.
