<p style="font-size: 20px; text-align: center">📈 IBA — Entry Test</p>

Prep resources for the IBA Karachi Aptitude Test (IBA-AT), used for undergraduate admissions (BBA and related programs) at the Institute of Business Administration, Karachi.

## 📋 About the Test

The IBA aptitude test typically covers Verbal Reasoning/English, Quantitative/Math reasoning, Analytical/Logical reasoning, and often an essay-writing component. It leans more towards aptitude and reasoning than pure FSc syllabus content, so rote memorization alone won't get you far here.

## 🗂️ Contents

This folder is currently a flat collection — consider organizing it as it grows:

```
IBA - Entry Test

```

## 📝 How to Use

1. Practice quantitative reasoning problems daily — they're pattern-based, not syllabus-based, so repetition builds speed.
2. Read editorials/opinion pieces regularly to strengthen verbal reasoning and essay writing.
3. Time-box analytical reasoning sections; these tend to eat the most time if you're not used to the question style.
