Getting the files

How to Download

You don't need to know Git to use this repo. Here are three ways to get papers and notes onto your computer, from easiest to most flexible.

Download everything (ZIP)

Best if: you're not sure yet which test you need, or just want it all
01

Open the repositroy on GitHub.

02

Click the green Code button near the top of the file list.

03

Click Download ZIP.

04

Once it's downloaded, extract (unzip) the file - you'll get one folder with every test's content inside, organized exactly like it is on GitHub.

Download just one test's folder

Best if: you only need one test's material and don't want everything else too
01

On GitHub, open the folder for the test you want - e.g. MDCAT, FAST, NUST.

02

Copy that folder's URL from your browser's address bar.

03

Go to a folder-download tool such as download-directory and paste the URL in.

04

Click Download - you'll get a ZIP with just that one folder, not the whole repo.

Clone with Git

Best if: you're comfortable with the command line and want to easily pull future updates
01

Install Git if you don't already have it.

02

Open a terminal and run git clone followed by the repo's URL (find it under the green Code button on GitHub).

03

Move into the folder Git created - you now have a full local copy you can update anytime with git pull.

Whichever method you use, files stay organized exactly like they are in the repo - by test, then by subject.
