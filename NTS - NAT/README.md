<p style="font-size: 20px; text-align: center">📝 NTS - NAT — National Aptitude Test</p>

Prep resources for the NTS National Aptitude Test (NAT), used by many universities across Pakistan as an admission or scholarship criterion.

## 📋 About the Test

NAT comes in several variants (NAT-IE for engineering, NAT-IM for medical, NAT-ICS for computer science, NAT-IBM for business, NAT-IGS for general science) — each with a different subject mix. Double-check which variant your target university requires before diving into past papers, since practicing the wrong variant wastes time.

## 📝 How to Use

1. Confirm which NAT variant you actually need before practicing.
2. Work through past papers under timed conditions — NAT is a single-sitting, multi-section test, so pacing across sections matters.
3. Revisit weak sections using the Books folder for concept review.
