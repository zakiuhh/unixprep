## 📖 About

This repo brings together past papers, subject-wise notes, MCQ banks, and prep material for the biggest entry tests FSc students in Pakistan sit for — all in one place, so you're not hunting across ten different Facebook groups and Telegram channels the night before your test.

## 🎯 Who This Is For

- FSc Part I & Part II students prepping for engineering, medical, business, or general university entry tests
- Anyone who wants organized, subject-wise past papers instead of scattered PDFs
- Students who want a quick reference for test format and what to expect

## 🚀 How to Use This Repo

1. Find the test you're preparing for in the folder list above.
2. Open that folder's README — it tells you what's inside and how it's organized.
3. Work through past papers by subject, then use the MCQ banks for timed practice.
4. Star ⭐ the repo so you can find it again during crunch week.

## 🤝 Contributing

Got past papers, notes, or a study trick that helped you? PRs are welcome:

1. Fork the repo
2. Drop your file in the matching test folder (create a new subfolder if it's a new subject/year)
3. Keep file names clear, e.g. `ECAT-Physics-2022.pdf`
4. Open a pull request with a short description of what you added

Please only contribute material you made yourself, or that's freely and legally shareable (like official past papers). See the note below before adding anything from a paid course or platform.
