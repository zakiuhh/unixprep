## 🎯 Why This Is Here

A lot of entry tests (especially FAST's) include a programming/logic component, and even where they don't, C++ fundamentals give you a head start once you're in a CS or engineering program. This folder is meant as a lightweight companion, not a full course.

## 📝 How to Use

1. Go through lectures in order (lec-1, lec-2, ... if you add more).
2. Practice the code examples yourself — don't just read them.
3. Pair this with actual past papers from your target test's folder for context on how much programming knowledge you actually need.
